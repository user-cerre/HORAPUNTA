# HORAPUNTA

Proyecto de programación de Inteligencia Artificial en Sistemas Operativos (UEX). Juego/ejercicio para cargar y visualizar tableros desde archivos de texto.

## Estructura del repositorio (resumen)

- src/ — código fuente ([src/main.cpp](src/main.cpp))  
- Salidas/ — tableros de prueba  
- include/, Enunciado/, .vscode/, etc.

## Requisitos

- Compilador C++ (g++/clang++) compatible con C++11 o superior.

## Compilar y ejecutar

```sh
g++ src/main.cpp -o horapunta
./horapunta
```

Al ejecutar se solicita seleccionar un tablero (1-7); el programa carga el archivo correspondiente y muestra el tablero en consola.
